# Isolated-worktree replay failure and repair (post-test)
The first isolated replay of 60 validation/test files failed BEFORE any cycle was run: `src/stage.py` assumed a prereg directory had already been created. A new empty worktree has no such folder. The repair adds `p.parent.mkdir(parents=True,exist_ok=True)` before serializing the fixed spec. This does not change the engine, its predictive choices, seeds, date splits, endpoints, benchmark inputs or pre-experiment source; it corrects the **retrospective reproduction script**. The initial failure remains recorded; a successful isolated replay must follow and must compare every raw JSON SHA-256, not merely finish without exception. This is not a fresh external replication.
